# 카드뉴스 편집기

**실제 주소 — https://creatoryoo.github.io/cc-cards/twist/** (모바일 브라우저에서 열기)

폰에서 카드뉴스 문구와 사진을 고쳐 **1080 × 1350 PNG**로 저장하는 편집기 모음입니다.
각 편집기는 파일 하나로 끝나며, 폰트·카드 디자인·PNG 생성기가 모두 안에 들어 있어
외부 요청 없이 동작합니다.

| 경로 | 편집기 | 장수 |
| --- | --- | --- |
| [`/twist/`](./twist/) | 비틀기 카드뉴스 — 익숙한 형식 + 나만의 반전 | 5장 |

## 쓰는 법

1. 폰 브라우저에서 `/twist/` 를 엽니다.
2. **글씨**를 탭하면 그 자리에서 고칩니다. 라임 강조는 그대로 남습니다.
3. **사진 칸**을 탭하면 사진첩이 열립니다. 16:9로 잘려 들어갑니다.
4. 키보드가 올라오면 하단 바는 접히고 오른쪽 위 **완료**만 남습니다. 완료를 누르면
   바가 다시 나오고, 고른 자리를 **↑ ↓ · 가 − 가 +** 로 옮기고 키울 수 있습니다.
5. **PNG 저장**으로 1080×1350 이미지를 받습니다. 아이폰은 이미지를 길게 눌러
   ‘사진에 저장’을 고르는 편이 확실합니다.

고친 내용은 그 브라우저의 `localStorage` 에 자동 저장되며, 서버로 보내지 않습니다.
원래대로 되돌리려면 PNG 화면 아래의 **수정한 내용 모두 지우고 원래대로**를 누릅니다.
